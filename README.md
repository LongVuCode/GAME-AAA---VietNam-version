# Project ĐỒNG CỔ (tên làm việc: HỒN TRỐNG)

Action RPG góc nhìn thứ ba lấy cảm hứng từ thần thoại, truyền thuyết, cổ tích và lịch sử Việt Nam (Unreal Engine 5, Windows).

## Bắt đầu đọc từ đâu
1. `CLAUDE.md`: luật làm việc
2. `reports/PHASE_0_REPORT.md`: báo cáo mới nhất
3. `docs/PLAN.md`: roadmap
4. `docs/GDD.md`, `docs/TECH_SPEC.md`
5. `docs/RESEARCH_PROTOCOL.md`, `research/`
